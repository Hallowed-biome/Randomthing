# Discord Bot Manager

Aplicativo Android simples para conectar um bot do Discord, listar servidores e canais acessíveis, visualizar mensagens e enviar mensagens.

## Estado atual

Estrutura inicial do projeto em preparação.

## Segurança

Nunca compartilhe o token do bot. O token é uma credencial secreta e deve ser tratado como uma senha. O aplicativo não deve registrar o token em logs nem incluí-lo no código-fonte.
